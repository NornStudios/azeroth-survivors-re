# Controls

**Azeroth Survivors** — third person, one hand on WASD, the other on the mouse.

| When | Key / Input | Action |
|---|---|---|
| Menu | Click a race, gender, class and zone | make your pick (**Randomize** rolls one) |
| Menu | **Enter** (or **Enter World**) | start the run; the world travels to the zone picked |
| Menu | **Esc** (or **Exit Game**) | leave the game |
| Playing | **W / S / A / D** or **arrow keys** | move the hero, relative to the camera; he faces where he runs (locked camera: world-relative, facing the cursor, backpedalling and strafing) |
| Playing | **Space** | jump |
| Playing | **F** (from level 5) | your class's movement spell: Blink, Charge… aim at the cursor |
| Playing | **C** | lock the camera into the top-down view / back to third person |
| Any | **G** | toggle the picture polish (`?grade=0` starts it off) |
| Playing | **mouse wheel** | zoom, from over the shoulder out to 70 yd |
| Playing | **drag** (camera unlocked) | swing and tilt the camera |
| Playing | **Esc** | pause |
| Playing | — | abilities cast themselves (no aim) |
| Level up | **1 / 2 / 3** (or click a card) | pick an upgrade |
| Paused | **Esc** | resume (**Quit game** leaves, **Abandon run** returns to the menu) |
| Game over | **Enter** (or **Play again**) | back to the menu |
| Any | minimap **+ / −** / minimize | minimap zoom / collapse |

The camera sits over the hero's shoulder, as the client's own does: a mouse drag swings and tilts
it, the wheel zooms from the shoulder out to 70 yd. **C** locks it into a top-down view
(laptop-friendly, and the genre's usual feel), where WASD is world-relative and the hero faces the
cursor; **C** again returns to third person. In the menu it slowly orbits the
preview hero. Your race, gender, class and zone are remembered across reloads.
